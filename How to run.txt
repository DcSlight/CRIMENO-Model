One-time setup (VLM now runs locally via Ollama, not a cloud API):
  1. Install Ollama: https://ollama.com/download  (auto-starts in tray on boot)
  2. ollama pull llama3.2-vision:11b   (~7.8GB, once)
     NOTE: do NOT use minicpm-v4.5/4.6 - they crash official Ollama (exit 0xc0000005),
     that model family needs an unofficial fork to run at all.
  3. pip install -r requirements.txt

Before each run: check Ollama's tray icon is running (it should auto-start). No API key needed for VLM anymore.

Step 1 - Broadcaster:
  python video_broadcaster.py videos/shop.mp4

Step 2 - Groq anomaly worker:
  python groq_anomaly_worker.py --ws_url ws://127.0.0.1:3000/ws/groq --decision-frames 60 --tracker-every 5

Step 3 - YOLO Tracker:
  python tracker_worker.py --device cuda --ws_url ws://127.0.0.1:3000/ws/tracker --send_overlay 0 --send_every_n_frames 5 --anomaly-endpoint tcp://127.0.0.1:5581

Step 4 - VLM layer (local Ollama, model=llama3.2-vision:11b; warms up on startup - watch for "[VLM] Warm-up result"):
  python vlm_worker.py --every 60 --ws-url ws://127.0.0.1:3000/ws/vlm --anomaly-endpoint tcp://127.0.0.1:5581

Simple scorer (mock vs. real logs, no Groq needed):
  python eval/score_logs.py                     (compares groq/logs_output.jsonl against the jewelry mock)
  python eval/score_logs.py --json out.json      (also writes the summary metrics to JSON, for the dashboard)
  python eval/score_logs.py --mock PATH --logs PATH   (point at different mock/log files)
