# How to run the CRIMENO surveillance system

# ARCHITECTURE:
# Broadcaster (5560) → Florence + Tracker (parallel)
#                   ↓
#            ┌─ Push to ZMQ 5581 (Qwen input) ─┐
#            ↓                                  ↓
#         Florence                           Tracker
#            ↓                                  ↓
#         Qwen (listens 5581, processes, pushes to 5582)
#            ↓
#      Message Broker (listens 5582, forwards WebSocket 3000)
#            ↓
#         NestJS (ws://127.0.0.1:3000)

# IMPORTANT: Each model uses separate ports to avoid "already in use" errors
# - Port 5560: Video broadcaster (PUB)
# - Port 5561: Video commands (REP)
# - Port 5581: Qwen input from Florence + Tracker (PULL)
# - Port 5582: Message broker input from workers (PULL)

# Process 1: Video Broadcaster
python video_broadcaster.py videos/shop.mp4

# Process 2: Message Broker (central hub - start FIRST)
python message_broker.py

# Process 3: Florence Worker (run in parallel terminal)
python florence_worker.py --device cuda --every 30

# Process 4: Tracker Worker (run in parallel terminal)
python tracker_worker.py --send_every_n_frames 1

# Process 5: Qwen Anomaly Detector (run in parallel terminal)
python qwen_anomaly_worker.py --device cuda
python video_broadcaster.py videos/shop.mp4
